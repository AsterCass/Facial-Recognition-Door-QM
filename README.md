## 应用于Linux/Windows的人脸识别项目

### 注意

1. Windows平台只用于项目调试，部分功能不可用
2. 当前项目还在迭代当中，部分功能可能不符合预期

[客户端文档](./client/README.md)

[服务端文档](./server/README.md)

### 技术栈

1. Qt
2. OpenCV
3. InspireFace 
4. Boost 
5. SQLiteCpp 
6. Breakpad
7. LibFacedetection

### 目标平台

Linux、Windows

### 功能支持

1. 人脸检测/识别
2. 网络连接支持：有线/4G/WiFi
3. 管理员密码、人脸识别参数、网络连接、光线参数等常用配置调整
4. 日志、备份上传
5. 人脸下发、修改、删除
6. IC卡、身份证下发、修改、删除
7. 实时开门
8. 已注册用户客户端直接录入人脸

### 基本流程

1. 启动服务端
2. 启动客户端（配置服务端地址）
3. 服务端调用下发人脸接口
4. 客户端1分钟内会收到人脸
5. 人脸核验成功
